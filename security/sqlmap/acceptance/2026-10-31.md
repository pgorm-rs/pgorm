## Scope

The full profile accounts for all 210 declared case-technique cells: 117 are
scheduled and 93 are explicitly inapplicable with retraceable reasons. The
identifier profile accounts for 66 cells: 28 scheduled and 38 explicitly
inapplicable. An inapplicable cell is not treated as evidence that the
corresponding identifier position is safe; those positions remain covered by
the direct identifier-render oracle and the direct SQL regressions.

The scanner result establishes that the protected HTTP fixture did not expose
SQL injection through the scheduled value, query, pipeline, graph, mutation,
identifier, ordering, pagination, enum and stored-state cases under these
profiles. It does not claim that arbitrary untested application code is safe.
